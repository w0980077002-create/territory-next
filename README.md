# TERRITORY 2.0

Новая самостоятельная Telegram RPG. Код, графика и интерфейс проекта TERRITORY 1.0 удалены из актуального дерева этого репозитория.

**Утверждённое ТЗ:** [TERRITORY_2_0_MASTER_TZ_RU.md](docs/TERRITORY_2_0_MASTER_TZ_RU.md)  
**Единственный утверждённый скрин:** [docs/reference/TERRITORY_2_0_APPROVED_2026-10-24.jpg](docs/reference/TERRITORY_2_0_APPROVED_2026-10-24.jpg)

## Неприкосновенные ограничения владельца

- Никакого использования кода, графики, миграций и игровых систем из TERRITORY 1.0.
- Нет профессий и игрового зала с мини-играми; эти разделы **удалены**, не скрыты.
- Любые новые художественные решения должны соответствовать утверждённому владельцем изображению.
- Прототип работает в автономной демонстрационной среде, не начисляет реальные средства и не использует production-аккаунты.
- Репозиторий действующей TERRITORY 1.0 `w0980077002-create/territory-game-builde` не изменяется.

## Запуск

```bash
npm ci
npm run dev
npm run typecheck
npm run test:v2
npm run build
```

Сборка V2 использует только `src/v2/`, `server/`, `supabase/functions/territory-v2-api/`, `public-v2/` и конфигурации текущего репозитория. Новые изображения генерируются из `scripts/generate-v2-original-art.mjs` при сборке. Демонстрационная страница: https://w0980077002-create.github.io/territory-next/ .

**История Git:** удаление файлов фиксируется коммитом. Старое содержимое всё ещё может присутствовать в предыдущих коммитах Git, пока не проведена отдельная перепись истории; это не является частью рабочего дерева новой игры.
