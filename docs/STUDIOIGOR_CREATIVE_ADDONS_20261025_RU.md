# Два новых бесплатных инструмента для TERRITORY 2.0 — 25.10.2026

По просьбе Сергея добавлены два инструмента автора [Студия Игор](https://github.com/studioigor). Это **средства разработки**; не заменяют и не изменяют уже утверждённый HUD, экономику или базу игроков.

## 1. 3D → 2D Sprite Sheet — конвертер для художника

- Копия исходного автономного приложения: [`tools/3d-to-2d/`](../tools/3d-to-2d/).
- Для телефона или без установки на компьютер: [официальная открытая версия Игоря](https://studioigor.github.io/3d-to-2d/).
- Ссылка на оригинал: [github.com/studioigor/3d-to-2d](https://github.com/studioigor/3d-to-2d), ревизия `7f9a8715ac01670ca499a74c6b7ebb68f002a439`.
- При локальной разработке: `npm run art:sprite-converter`, затем [http://127.0.0.1:8765](http://127.0.0.1:8765) на компьютере, где выполняется команда. Python входит в инструменты сборки; npm-зависимости игре не добавляются.
- Загружать **собственные** `.glb`, `.gltf`, `.fbx`, `.zip` с настоящей анимацией; выбрать ракурс, анимацию, FPS/количество кадров, размер и скачать PNG или ZIP.
- Для героев и спутников V2 использовать ракурс в сторону **вправо**, для врагов/боссов — **влево**, сверить с фактическим боевым референсом. Экспорт не гарантирует риг, плавную атаку или правильную точку попадания — проверять отдельно.
- Это **не** преобразователь статичной 2D-картинки в живого бойца. Для нарисованного 2D-персонажа продолжает работать `ref2game`.
- Зависимости Three.js, JSZip и FileSaver.js из исходного приложения подключаются через CDN; без интернета приложение может не запуститься. Платная подписка и API-ключ не нужны. Конвертер не встраивается в сайт игры, чтобы не нарушать правило изоляции одобренной V2-публикации.

## 2. Lighthouse UIKit — навык сборки интерфейса по эталонам

- Локально установлен оригинальный навык: [`.agents/skills/reference-uikit/SKILL.md`](../.agents/skills/reference-uikit/SKILL.md).
- Полные вспомогательные материалы: `references/paint-and-assets.md`, `references/verification-and-delivery.md`, `scripts/audit_bundle.py`.
- Исходник: [github.com/studioigor/lighthouse-uikit](https://github.com/studioigor/lighthouse-uikit), ревизия `3bdb743a09e16b8116a1b72dceed5671a0c572e5`.
- Перед изменением экранов изучать [канон](TERRITORY_2_0_CANON/SOURCE_OF_TRUTH_RU.md): настоящий отдельный текст на рисованном фоне, правильные растяжимые рамки, кнопки в стиле наших ярких викингов, компоненты с состояниями и адаптация на **320 и 390 px**.
- `audit_bundle.py` проверяет экспортируемые папки/архивы на служебные файлы, признаки личных данных и секретов; это вспомогательная, а не исчерпывающая проверка.
- Исходный морской UI, изображения маяков, скриншоты, предметы и шрифты **не переносились** в игру — эстетика TERRITORY не меняется.

## Граница и происхождение

В `studioigor/3d-to-2d` MIT указан в README без отдельного файла `LICENSE`. У `studioigor/lighthouse-uikit` отдельного `LICENSE` на момент импорта нет; пользователь сообщил о разрешении автора на использование открытых материалов. Сведения о точных ревизиях и пределах переноса — в `SOURCE_NOTICE.md` рядом с каждым инструментом. Это **не подтверждение лицензий сторонних 3D-моделей, музыки, шрифтов или картинок**.

Проверка целостности: `npm run qa:creative-addons`. При сборке `npm run build` мастерская **не попадает** в `dist/`: игровой бандл остаётся в `src/v2/`, публичная папка — только с утверждёнными V2-файлами.
