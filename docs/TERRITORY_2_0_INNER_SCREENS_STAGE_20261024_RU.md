## Технические границы
- Все картинки — из уже лежащих в `public/` оригинальных игровых ресурсов TERRITORY, не из чужого видео.
- Главная сцена боя, фоновый ландшафт, сферы, экипировка и нижние 5 кнопок не переписывались.
- Реализованные действия действуют **только в V2 демоверсии**. Почта не начисляет награды, а механики неподключённых игр/кланов/рефералов не притворяются запущенными.
- Не было изменений в TERRITORY 1.0, её GitHub-репозитории, production Supabase, VIP или админке.
- `npm run typecheck` и `npm run test:v2` проверяются GitHub Actions перед автоматическим развёртыванием тестового GitHub Pages.

## До будущего полного релиза
Остаются: настоящая серверная почта и квитанции, отдельное PvP, кланы, испытания, игровые автоматы, достоверные реферальные бонусы, внутриигровая экономика магазина и ручная мобильная сверка pixel-diff по эталону на Android/iPhone. Указанные разделы **не считаются полностью реализованными игровыми механиками** на основании одного визуального пакета.
