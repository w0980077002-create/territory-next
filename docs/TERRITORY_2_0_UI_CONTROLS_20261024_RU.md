# TERRITORY 2.0 — приёмка кнопок и единой HUD-системы

Дата: 24 октября 2026. Этап визуального ТЗ VUI-01, VUI-04–VUI-10, SCR-01. Реализация в `territory-next`, **не в TERRITORY 1.0**. Единственный художественный образец: `docs/reference/TERRITORY_2_0_APPROVED_2026-10-24.jpg`.

## Сделано в игре

1. **Единый набор боковых кнопок.** Семь слева, три справа и отдельно меню-решётка и Арена. Иконки теперь получают одинаковые объёмные золотистые рамки, блики, тени, отступы и эффект нажатия. Длинные подписи центрируются и переносятся по словам. Меню отображается как четыре ячейки **без дублирующей подписи**, но остаётся доступным для скринридера.
2. **Нижняя навигация.** Вместо пяти разрозненных тёмных прямоугольников — единый бар из дерева/металла с выразительными плавающими иконками. Позиции: Порт / Навыки / **БОЙ** / Приключение / Магазин. Главный БОЙ — приподнятая синяя шестиугольная кнопка с оружием и счётчиком побед; используется настоящий обработчик боя. Для Навыков создана новая оригинальная векторная иконка книги.
3. **Контроль боя под складом.** Скорость ×1/×2 отражает фактическое состояние на кнопке и имеет `aria-pressed`. Круговая кнопка автобоя меняет оформление в зависимости от работы, тоже имеет `aria-pressed`. Кнопка рейтинга с новой оригинальной золотой короной вызывает работающий экран рейтинга. Ни одна из кнопок не является декоративным изображением без действия.
4. **Окна задания и экипировки.** Согласованные рамки из тёмного дерева, золотого металла, кремовые плитки вещей и контрастные уровни; контролы не перекрывают центр, поскольку между заданием и действиями сохраняется выделенное место для шестиугольной кнопки.
5. **Качество мобильного интерфейса.** Отдельные правила ширины ≤370px, низкой высоты ≤650px, `safe-area-inset-bottom`, фокус с клавиатуры, состояния нажатия и `prefers-reduced-motion`.

## Файлы и проверка

- `src/v2/owner-ui-controls.css` — последний импорт после старых CSS, чтобы новые правила были единым источником визуальной правды.
- `src/v2/NextApp.tsx` — улучшенный UI-маршрутизатор, новые навигационные ассеты, обратная связь переключателей.
- `public/v2-ui-skills-book.svg`, `public/v2-ui-crown.svg` — оригинальные графические ресурсы TERRITORY.
- `scripts/check-v2-owner-controls.mjs` — обязательный тест на набор кнопок, отсутствие изменения фона, наличие изображений и состояний кнопок; `npm run test:owner-controls` и `npm run test:v2`.
- Сборка `npm run typecheck && npm run test:v2 && npm run build` должна проходить перед автоматической GitHub Pages публикацией.

## Ещё требует проверки владельца

Этот этап — **реальная реализация CSS/JSX, но не визуальная приёмка 1:1**. На пользовательском Samsung после публикации нужно оценить ширину переносов, высоту нижнего бара и выраженность иконок. Не вводить новые фоны или неподтверждённые детали ради этих правок. Внутренние экраны и полное подключение защищённой онлайн-экономики остаются отдельными этапами по Master ТЗ.
