# TERRITORY 2.0 — БЕЗУСЛОВНЫЙ ЗАПРЕТ ПЕРЕНОСА TERRITORY 1.0

**Решение владельца:** 24 октября 2026 года. **Статус:** обязательное правило разработки. Приоритет над любыми прежними формулировками об использовании «наследия», «старых ресурсов» или «переносе» первой игры.

## 1. Что категорически нельзя брать из TERRITORY 1.0

- Графику: фоны, персонажей, боссов, спутников, иконки, предметы, изображения магазинов, анимации, звуки, плашки и готовые экраны.
- Код: React-компоненты, CSS, интерфейсные шаблоны, маршруты, движки, игровые конфигурации, экономические формулы, методы сохранения, старую аутентификацию и любые пакеты с логикой первой игры.
- Данные и инфраструктуру: реальные аккаунты, VIP, инвентарь, Supabase production, Telegram-бота, ключи, серверы, API и незапрошенные миграции.
- Обходные варианты: переименовать старую картинку или переложить старую компоненту в `src/v2` — **НЕ является созданием новой игры**.

Совпадения некоторых названий разделов с первой TERRITORY допустимы **только если они прямо входят в утверждённое ТЗ 2.0**. Их реализация обязана быть новой.

## 2. Единственный художественный стандарт

Референс дизайна новой TERRITORY 2.0: [утверждённый скрин 24.10.2026](reference/TERRITORY_2_0_APPROVED_2026-10-24.jpg). Файл изображения — единственный утверждённый стандарт вида главного экрана; любые дополнительные художественные формулировки не считаются требованиями. Ни один старый экран не имеет права заменять его. Принятый для V2 фон `v2-winter-stage-v5.webp` сохраняется без редактирования, как ранее велел владелец; эта V2-специфичная иллюстрация не является разрешением на использование ресурсов V1.

## 3. Текущая техническая изоляция

- Вход запускает `src/v2/main.tsx`; весь геймплей новой демоверсии под `src/v2`.
- `vite.config.ts`: **publicDir = public-v2**. В `dist/` публикуются только ресурсы `public-v2/`, а не всё содержимое старой папки `public/`.
- `scripts/generate-v2-original-art.mjs`: создаёт новые самостоятельные SVG для героев, спутников, врагов, боссов, экипировки, интерфейса и сцен.
- `src/v2/core/legacyAdapter.ts` удалён как недопустимый старый адаптер.
- `scripts/check-v2-original-art-isolation.mjs`: провалит сборку при появлении старых импортов и ресурсов, а после `vite build` проверит публикуемый артефакт.
- Все новые изображения этого первого пакета — **начальные оригинальные векторные прототипы**. Их не следует выдавать за полностью завершённую качественную финальную графику из эталона.

## 4. Что остаётся сделать

Исторические файлы V1 ещё могут оставаться в **дереве Git/repository history**, но **не должны импортироваться и не должны попадать в сборку TERRITORY 2.0**. Это не означает, что репозиторий уже полностью очищен от архивных файлов. До финального релиза — отдельная очистка дерева только новой игры с полным тестом зависимостей.

Визуальная приёмка **1:1 по изображению на настоящих Android/iPhone не выполнена**. Не утверждать обратное. Серверное PvP, платёжные механики и реальная экономика также не считаются готовыми, пока их поведение не проверено.

## 5. Ограничение полномочий

Вся разработка ведётся только в `w0980077002-create/territory-next`, в V2-ветке. Изменения первой TERRITORY, её живой базы и бот-адреса запрещены. Публикация изолированной демоверсии не является запуском игры для существующих игроков.
