# TERRITORY 2.0 — статус разработки и самостоятельный бэклог

Дата фиксации: 2026-10-24. Рабочий репозиторий: `w0980077002-create/territory-next`.

## Что реализовано

- Полная копия исходников TERRITORY 1.0 и подготовительной ветки 2.0 перенесена **в отдельный репозиторий**; игровые ассеты, анимации, компоненты и история функциональности доступны как исходный материал.
- Новый `index.html` запускает **собственный** `src/v2/main.tsx`, а не старый `src/main.tsx`. Старый Telegram-вход не вызывается.
- Сделан новый `NextApp.tsx`: шапка, игровые валюты (все демо), глава, бой вправо, враги, спутник, анимации, HP, энергия, панель из 7 слотов экипировки, боковые кнопки, Арена над голубым орбом, Порт/Навыки/Бой/Приключение/Магазин.
- В новой главной оболочке открываются разделы героя, склада, навыков, рун, последователей и приключений. Изменение класса, руны, спутника и главы влияет на демонстрационный бой. Остальные страницы пока маршрутизированы как подготовительные экраны.
- Отдельный `src/v2/core/autoBattle.ts` считает демонстрационный бой с разными героями, рунами, типами спутников и боссами. Боевой симулятор не имеет доступа к деньгам, инвентарю или облачным сохранениям.
- `src/v2/core/legacyAdapter.ts` — read-only проекция существующего сохранения, без изменения ID предметов/последователей.
- `src/v2/battleStonePolicy.ts` запрещает списание одного камня за каждого обычного врага; специальные режимы оставлены до серверных правил.
- Убраны старые workflow публикации из нового репозитория. `src/game/supabase.ts` содержит блокировку действующей базы и требует явного разрешения независимого staging.

## Что уже проверяется автоматически

- `npm run typecheck`: типизация всего перенесённого проекта.
- `npm run test:v2`: изолированный интерфейс, вариации боевого движка, безопасная точка входа.
- `npm run build`: сборка с фиктивной, не действующей базой.
- Отсутствие старого Pages workflow и запрет случайного возвращения прежнего Telegram/production логина в новую стартовую страницу.

## Жёсткие границы
Этот репозиторий — **новая игра, не новый экран существующей продакшен-игры**. Никаких изменений `territory-game-builde/main`, старой Supabase, старого бота или живых аккаунтов. Ни один визуальный прототип не должен выдавать реальные предметы/алмазы. Полный релиз ещё не готов.
