# TERRITORY 2.0 — ЭКРАН ЗА ЭКРАНОМ, КНОПКА ЗА КНОПКОЙ (UI/UX-КОНТРАКТ)

**Приложение** к [Master ТЗ](TERRITORY_2_0_MASTER_TZ_RU.md). Источник главного UI — **только [единственное фото владельца](reference/TERRITORY_2_0_APPROVED_2026-10-24.jpg)**, реальный исходник 864×1536.  
**Статус точности:** главный экран утверждён и визуально проверяем 1:1. **Скриншоты внутренних окон в переписке как окончательный эталон не утверждены**, поэтому нельзя честно объявлять их точную геометрию «1:1 из игры-конкурента». Ниже фиксируются **функциональные контракты** этих окон и правило сохранять стиль главного изображения.

## 1. Схема утверждённого кадра

| Слой | Что видно буквально на эталоне | Что реализовать |

| Left seven | `Задания`, `События`, `Друзья`, `Награды`, `Приглашение`, `Социальные награды`, `Морской набор` | 7 ярких художественных кнопок, индикатор только когда награда реально готова |

**Нельзя:** механически «рисовать» в игре текст из таблицы как статическую картинку. Все динамические значения должны принадлежать state/data, а оригинальная композиция — layout и asset layers. Референс не заменяется рекламой Lootborn/COC.

## 2. Общий контракт каждого внутреннего экрана

Каждая страница использует те же рамки, объёмные иконки, шрифтовую читаемость, яркие цвета, фон и общую навигационную логику. При открытии: доступна кнопка «Назад», закрытие, экранное имя, узнаваемая активная вкладка, содержимое, информация об ограничениях, состояние сети и server-confirmed actions. Внизу не допускать перекрытия Telegram. Раздел при отсутствии данных говорит, *что именно отсутствует*, и показывает допустимые действия. **Изображение для невиданного внутреннего экрана нельзя объявлять окончательно согласованным** без отдельного визуального решения владельца.

## 3. Контракт 34 экранов (интерактивный сценарий и негативные состояния)

### SCR-01. Главный бой

**Поля:** avatar, level, VIP, wallet, power, chapter/stage, wave/boss progress, hero/companions/enemies, HP/energy, equipment, task, speed, auto, shortcuts. **Клик:** главные боковые кнопки, gear focus, enter, arena, +currency, quest, auto/×2, navigation. **Данные:** server snapshot plus streaming battle events. **Ошибки:** нет соединения — восстановление, нельзя подменять победу; closed stage — причина; reconnect — не новый loot receipt. **Приёмка:** VUI-01…10 + E2E-005…019.

### SCR-02. Герой

**Поля:** имя/Telegram ID mapping только для владельца, фото, класс, уровень, XP, сила, характеристики, внешность, 7 существующих наследованных слотов и только отдельно версионированные новые. **Вкладки:** снаряжение/навыки/руны/спутники/склад. **Кнопки:** выбрать допустимый класс, открыть слот, надеть/снять, внешний вид, сравнить. **Ошибка:** неизвестный slot/unlock или предмет другого playerId, не вычитать currency. **Тест:** E2E-020/024/026.

### SCR-03. Склад

**Поля:** все предметы и количество, текущий надетый слева/выбранный справа; фильтр оружие/шлем/щит/обувь/аксессуары/материалы/спутники; сортировка по уровню/качеству/дате. **Действия:** equip/unequip, compare, upgrade, forge, favorite/lock, dismantle, mass salvage, pagination. **Ошибка:** чужой/stale/favorite/equipped item, пустой склад, нехватка материалов. **Тест:** E2E-024…029.

### SCR-04. Навыки

**Поля:** выбранный класс, базовые/ключевые/контрольные/ультимативные/пассивные умения, доступность, разъяснение эффекта/кулдауна, встроенные руны. **Действия:** экипировать, снять, заменить, открыть сведения, перейти к рунам/билду. **Ошибка:** неизвестный/запрещённый навык, занят слот, изменённые правила, отсутствует ресурс. **Тест:** E2E-020/021/022.

### SCR-05. Руны

**Поля:** категории, совместимые навыки, свойства, редкости, модификаторы/статусы, ресурс улучшения, имеющиеся и вставленные. **Действия:** preview эффекта, сравнить, вставить/снять, улучшить после серверного подтверждения. **Ошибка:** руна не подходит, ресурс закончился, stale loadout revision. **Тест:** E2E-022/023.

### SCR-06. Комплекты

**Поля:** `setId`, сколько надето, доступные бонусы, конкретные item instances, отдельные dark-сеты. **Действия:** перейти к нужному предмету, посмотреть из чего собрать набор, визуально увидеть изменение при снятии. **Ошибка:** неучтённый слот, ghost bonus после unequip, чужая вещь. **Тест:** E2E-025/029.

### SCR-07. Гравировки и реликвии

**Поля:** ячейки, ранг, эффекты, источники, материал, locked/favorite, сезонный/постоянный тип. **Действия:** выбрать, слить, заменить, пробудить с предварительным просмотром расхода. **Ошибка:** несовместимый предмет, сезонная потеря постоянной реликвии, повторный craft. **Тест:** E2E-028/048.

### SCR-08. Спутники

**Поля:** коллекция, основная позиция, поддержка, имя/роль/уровень/таланты/ауры/пробуждение; отдельный взрослый боевой бык/корова TERRITORY. **Действия:** выбрать основного, назначить поддержку, прокачать, открыть описание ауры, снять. **Ошибка:** один экземпляр в двух несовместимых позициях, неверный ID, недостаток ресурсов. **Тест:** E2E-030.

### SCR-09. Приключение

**Поля:** карта глав, текущий узел, пройденные этапы, открытые биомы, элита, боссы, этапные задания. **Действия:** выбрать разрешённый этап, увидеть условия, войти в бой, посмотреть награды без фиктивной выдачи. **Ошибка:** закрыто/уже пройдено/сбой загрузки. **Тест:** E2E-010/017.

### SCR-10. Испытания и функции

**Поля:** карточки этажных подземелий, Dark-energy-подобные режимы, рейды, отдельные боссы, лимиты/попытки и достижения. **Действия:** открыть условия, выбрать этаж, оплатить попытку один раз, открыть leaderboard, начать/завершить. **Ошибка:** исчерпаны попытки, босс другой фазы, слабая сеть. **Тест:** E2E-031/032.

### SCR-11. Арена

**Поля:** соперники, сила/билд, поиск, рейтинги, PvP сцена, живой чат и **компактные сворачиваемые эликсиры у чата**, результат. **Действия:** выбрать бой, применить эликсир/действие, отправить сообщение, посмотреть рейтинг, вернуться. **Ошибка:** один игрок против самого себя, stale match, чат закрыт после 30 минут, антиспам. **Тест:** E2E-033…036.

### SCR-12. Порт

**Поля:** гавань, добыча и корабли, состояние каждого таймера и ресурсов. **Действия:** открыть шахту, портовый рейс, склад и рынок; получать подтверждённый результат один раз. **Ошибка:** второй активный job, неверное время клиента, stale voyage. **Тест:** E2E-043/045.

### SCR-13. Раздел исключён владельцем

**Статус:** удалён из нового проекта. Элементы навигации и механики не создаются. Номер сохраняется только ради постоянства нумерации контрактов. **Тест:** E2E-044 подтверждает отсутствие маршрута.

### SCR-14. Кузница

**Поля:** выбранный предмет, надетая альтернатива, статы до/после, материалы, стоимость, ожидаемый результат/шанс если официально установлен. **Действия:** upgrade, reroll, forge, dismantle, back. **Ошибка:** нет ресурса, предмет изменён/удалён, незаконный slot. **Тест:** E2E-027/028.

### SCR-15. Магазин

**Поля:** категории, валюты, цены и содержимое пакета, лимиты, период, статус доступности, остатки. **Действия:** просмотр карточки, подтверждение, покупка через server settlement, история. **Ошибка:** не хватает currency, продукт изменился, уже куплен, платёж отклонён. **Тест:** E2E-050/051/052.

### SCR-16. Специальный рынок

**Поля:** временные товары, дедлайны по серверному времени, цены/остатки, условия покупки, реальные ограничители. **Действия:** открыть карточку, купить единожды, сменить доступный раздел. **Ошибка:** истёк товар, лимит, currency stale. **Тест:** E2E-051/052.

### SCR-17. Первый взнос / VIP

**Поля:** VIP 0…10 как собственное направление, первый пакет, список эффектов, стоимость, условия, чек/получение. **Действия:** посмотреть, оплатить только через проверенного провайдера, сверить получение. **Ошибка:** повторный webhook, неподходящий регион/возраст, покупка отключена. **Тест:** E2E-051.

### SCR-18. Задания

**Поля:** основная/ежедневная/недельная вкладки, текущие цели, прогресс `n/m`, призы, таймер по серверу. **Действия:** перейти к цели, получить доступный приз, просмотреть выполненные. **Ошибка:** необоснованный claim, период истёк, повторный тап. **Тест:** E2E-039/052.

### SCR-19. События / Награды

**Поля:** активные временные акции, ежедневные посещения, рейтинги, период, collect badges, сезонные очки. **Действия:** открыть/участвовать/забрать. **Ошибка:** окончился период, повторная выдача, неизвестные условия. **Тест:** E2E-036/050/052.

### SCR-20. Друзья и приглашения

**Поля:** собственная ссылка/код, список рефералов и условия, ясный прогресс до подтверждённого уровня. **Действия:** скопировать/поделиться, открыть список, получить только eligible reward. **Ошибка:** self-referral, дубли, не выполнил порог, подозрительное приглашение. **Тест:** E2E-037.

### SCR-21. Социальные награды

**Поля:** доступное действие, требуемое подтверждение, лимит, время, приз, история. **Действия:** открыть соцзадание, получить проверенный статус, забрать. **Ошибка:** неподтверждённое действие, повторная выдача. **Тест:** E2E-038/050.

### SCR-22. Морской набор

**Поля:** карточка моря/кораблей/материалов, состав и цены пакета, срок, статус приобретения. **Действия:** открыть состав, вернуться в порт, купить если реально доступно. **Ошибка:** недоступный пакет, не проверен платёж, повторная доставка. **Тест:** E2E-051.

### SCR-23. Корабли / Плавания

**Поля:** корабли/слоты/маршруты, экспедиция, время возврата, груз, забираемый итог. **Действия:** выбрать корабль/маршрут, отправить, просмотреть/получить результат. **Ошибка:** корабль уже в плавании, неверное server time, повтор claim. **Тест:** E2E-045.

### SCR-24. Клан / Гильдия

**Поля:** имя/герб, список/роли, вклад, общий event, журнал, рейтинг/награды и ограничения. **Действия:** создать/вступить/покинуть, вклад/клановые задания, руководить только при соответствующей роли. **Ошибка:** нет роли, награда после выхода, дублированный вклад. **Тест:** E2E-041.

### SCR-25. Рейтинг

**Поля:** категория, период, позиция, очки/победы, rewards preview, отметка закрытого сезона. **Действия:** смена рейтинга, просмотр профиля, получение законной сезонной награды. **Ошибка:** устарел snapshot, повторное начисление, закрытие сезона. **Тест:** E2E-036.

### SCR-26. Игровой зал

**Поля:** 5 карточек слотов, билеты/условия, первая мини-игра «Сокровищница», «Монополия», собственный слот; ещё две игры TBD. **Действия:** выбрать игру, показать цену и правила, подтвердить вход, получить результат по receipt. **Ошибка:** билетов не хватило, повтор раунда, платная игра отключена. **Тест:** E2E-046/047.

### SCR-27. Почта и рассылки

**Поля:** системные/личные/админские письма, `read/claimed`, вложения (до 3 наград), срок и время. **Действия:** прочитать, забрать, вернуться/архивировать; у owner — запланировать отправку. **Ошибка:** второй claim, частичный коммит 3 наград, просроченное письмо. **Тест:** E2E-039/040.

### SCR-28. Настройки

**Поля:** графика, качество, эффекты, звук, музыка, язык, фоны боя и города, уведомления. **Действия:** открыть превью 5 вариантов фона для старта (позже до 10), выбрать, посмотреть активный, отключить motion. **Ошибка:** файл фона не загрузился, unsupported device, настройки не повлияли на кошелёк. **Тест:** E2E-009.

### SCR-29. Админка

**Поля:** online now/today/7 days, игроки, профили/операции, подозрительные, подарки до 3 за письмо, расписания, анонсы, бан и права. **Действия:** рассылка, пересмотр операции, предупредить, решение ban/unban только владельцу, аудит. **Ошибка:** player пытается вызвать owner endpoint; повторная рассылка; защита старого скрытого входа. **Тест:** E2E-040/042, SEC-10.

### SCR-30. Сезонная экспедиция

**Поля:** отдельный временный персонаж/силы события, рюкзак, таймер, доступные ресурсы, противники, цель эвакуации, три предлагаемых buff. **Действия:** войти, собрать, выбрать один, извлечь/проиграть. **Ошибка:** не открыт режим, два одновременных outcome, спутаны временные и постоянные предметы. **Тест:** E2E-048/049.

### SCR-31. Сезонные ресурсы

**Поля:** сезонные камни/гравировки/таланты, качество, эффект, срок, условия/история прошлых сезонов. **Действия:** получить/улучшить/оснастить только в открытом режиме, увидеть завершение периода. **Ошибка:** игрок теряет постоянное после reset; неверный период. **Тест:** E2E-048/052.

### SCR-32. Промокоды

**Поля:** поле ввода, условия, срок, краткое имя акции, результат. **Действия:** ввести, подтвердить, увидеть приз/отказ. **Ошибка:** повтор, просрочен, чужой регион, недопустимый аккаунт. **Тест:** E2E-038.

### SCR-33. Уведомления

**Поля:** внутриигровые письма/время готовности ресурса/новые события/доступный приз, категория и статус. **Действия:** прочитать, перейти к источнику, выключить выбранную категорию. **Ошибка:** push с секретом, спам, повторное уведомление как новый приз. **Тест:** E2E-052.

### SCR-34. Справка / каталог механик

**Поля:** объяснения всех статов/типов валют, предметов, шансов когда раскрыты правилами, стоимость/таймер/лимиты, источники добычи, доступность VIP, правила PvP и отказов. **Действия:** открыть из любой сложной формы, найти объяснение, вернуться на прежнее место. **Ошибка:** параметры TBD — не показывать фальшивую цифру. **Тест:** SEC-05 + проверка справочного контента по `rulesetVersion`.

## 4. Единый словарь взаимодействий и состояний

| Состояние | Что видит игрок | Что делает приложение |
|---|---|---|
| `unopened` | информация с условиями доступа | без расхода |
| `loading` | короткий индикатор, сохранение ориентира | запрос чтения, отмена устаревшего |
| `ready` | интерактивная карточка/форма | валидные доступные действия |
| `empty` | понятная причина и следующий шаг | без ложной награды |
| `pressed` | feedback на нажатие | подготовка команды с operationId |
| `pending` | одно действие в обработке | запрет дублирующего расходного запроса |
| `success` | реальные changes/receipt | синхронизация server revision |
| `rejected` | причина: закрыто/дорого/не подходит/лимит | нет потери данных |
| `conflict` | «состояние обновилось» | reload snapshot, не молчаливое перезаписывание |
| `offline` | баннер и безопасная демонстрация/прочитанное | никакого начисления по local clock |
| `expired` | повторная авторизация/конец события | новая сессия/правило только с сервера |

## 5. Требования к ассетам и анимациям

- Каждый персонаж хранится **индивидуальным прозрачным изображением/набором кадров**, не общей коллажной картинкой, с корректным pivot стоп и направлением. Герои/спутники направлены вправо; противники/боссы влево.
- Пакет на роль (где применимо): `idle, move, attack, cast, block, dodge, hit, death`, для боссов дополнительное состояние фаз; animation events должны соответствовать расчётным hit frames.
- Художественное согласование **через один кадр фото**, без детского вида, мутности, неправильной перспективы или накладывания подписей на персонажей. Цифры HP/урона — DOM/Canvas overlay, а не запечённая надпись на картинке.
- Для сцен использовать отдельные области `world background / distant scenery / ground / actors / combat effects / HUD`, с прозрачностью, разными z-index, переключаемой плавностью и безопасным scaling.
- `Motion reducing`: выключать мигание, вспышки и параллакс, сохраняя все игровые события.
- Лицензии графики, музыки, шрифтов, моделей и спецэффектов фиксировать в `asset_manifest`, не приносить прямой чужой artwork. **Само утверждённое фото — визуальный эталон, не лицензия на копирование чужих материалов.**

## 6. Условия закрытия экрана

Каждый из 34 имеет:
1. Доступный route + возврат с сохранённым фокусом;
2. Достаточные реальные поля + loading/empty/offline/error/locked;
3. Разделение read/command и корректные права;
4. Минимум положительный и негативный тест;
5. Просмотр на мобильных/бездеятельная кнопка не считается реализацией;
6. Согласованность визуальных решений с одним главным фото.

Связь c кодовой приёмкой — в [матрице 55 E2E](TERRITORY_2_0_ACCEPTANCE_AND_TRACEABILITY_RU.md). **Нельзя объявить внутренние экраны идеально воспроизведёнными «1:1», пока нет соответствующих подтверждённых изображений/сценариев; описание выше — подробный функциональный контракт для собственной TERRITORY 2.0.**
